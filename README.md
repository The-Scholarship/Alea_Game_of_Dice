# Alea_Game_of_Dice

## Game rules

### Mayores

Mayores (or Greater) is the simplest dice game documented in the Castilian manuscripts "Libro de los Juego" by Alfonso X.
It's a game of luck relying on a single simultaneous throw.

#### Rules

This game is meant for 2 players with 3 six-sided dice. 

1. Both players roll the three sice simultaneously.
2. The pip values are summed.
3. The player with the highest total score wins the stakes. If the totals are equal, the roll is a tie and must be recast.

### Tanto en uno como en dos

Tanto en uno como en dos (As much in one as in two) is another traditional dice game documented in Alfonso X's "Libro de los juegos". Victory depends on a specific mathematical combination rather than the highest total sum.

#### Rules

This game is meant for 2 players with 3 six-sided dice.

1. Both players roll the three dice simultaneously.
2. To win, a player must roll a combination where the pip value of one die exactly equals the sum of the other two dice (e.g., rolling a 5, a 3, and a 2, because 3 + 2 = 5).
3. If both players roll a winning combination, the player with the highest matching number wins (e.g., a 6 made of 4+2 beats a 5 made of 3+2). If neither player rolls a valid combination, the dice are recast.
